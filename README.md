# Osito Progress Tracker

Necesito que me repliques el repositorio llamado osito para ver el progreso del trabajo. Y dame un prompt de mejoras de funcionalidades, haceme de debug, nunca de ningun aspecto visual. En Saq tiene que funcionar para que la gente pueda subir los productos así que armé un dashboard para eso. También ACM de debug de todos los clics. Fíjate que tenga aspect ratio para teléfono, para computadora y también
